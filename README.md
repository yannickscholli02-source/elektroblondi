# ⚡ Elektroblondi Website

Moderne, responsive Website für **Jenna (@elektroblondi)** – Elektronikerin für Betriebstechnik & Content Creatorin.

![Preview](https://images.squarespace-cdn.com/content/v1/663b6072f99df73a91f85bfd/ccea86ec-6f4d-4c4d-9e0c-c0b9ba49f6c2/IMG_3457+%281%29.jpg)

## 🚀 Features

- **Modernes Dark Theme** mit elektrischem Gelb/Orange Farbschema
- **Vollständig responsive** für Desktop, Tablet und Mobile
- **Animierte Galerie** mit automatischem Scroll-Effekt
- **Scroll-Animationen** für Fade-In Effekte
- **Werkzeug-Showcase** mit Produktkarten
- **Newsletter-Anmeldung**
- **Mobile Navigation** mit Hamburger-Menü

## 📁 Struktur

```
elektroblondi-website/
└── index.html      # Komplette Website (Single-File)
```

## 🛠️ Technologien

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid, Animationen)
- Vanilla JavaScript
- Google Fonts (Bebas Neue, DM Sans)

## 🌐 GitHub Pages Deployment

1. Repository auf GitHub erstellen
2. Dateien hochladen
3. Settings → Pages → Source: `main` branch → Save
4. Website ist verfügbar unter: `https://[username].github.io/[repo-name]/`

## 📱 Sektionen

- **Hero** – Vorstellung mit Profilbild
- **Stats** – Kennzahlen
- **Über Mich** – Persönliche Geschichte
- **Galerie** – Bildergalerie mit Scroll-Animation
- **Karriere** – Job-CTA für Heldele
- **Werkzeug** – Empfohlene Produkte
- **Newsletter** – E-Mail-Anmeldung
- **Footer** – Links & Social Media
